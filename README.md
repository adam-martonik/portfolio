# Osobné portfólio | Adam Martonik

Zdrojový kód môjho osobného portfólia, kde prezentujem svoje programátorské zručnosti, univerzitné/osobné projekty a pracovné skúsenosti. Stránka je navrhnutá ako responzívna Single Page Application (SPA).

🌐 **[Pozrieť live verziu webu](https://adam-martonik.github.io/portfolio)**

## 🛠️ Technologický stack

- **Frontend:** React (JavaScript)
- **Build tool:** Vite
- **Štýlovanie:** Čisté CSS (Custom vlastnosti a Flexbox/Grid systém)
- **Deployment:** GitHub Pages (`gh-pages`)

## 💻 Lokálne spustenie

Ak si chceš projekt spustiť lokálne, postupuj podľa týchto krokov:

1. **Clone Repo**
   ```bash
   git clone [https://github.com/adam-martonik/portfolio.git](https://github.com/adam-martonik/portfolio.git)
   cd portfolio
2. **Dependencies**
   npm install
   npm install lucide-react framer-motion
   
3. **Deploy locally**
   npm run dev
